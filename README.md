# Cure rate and SurvSHAP Modelling

These files are based on an article titled: *From Cure Rate Models to Explainable Survival Analysis: SurvSHAP Based Insights for Credit Risk* to appear in the Journal of Applied Stochastic Models in Business and Industry.

The Prosper P2P data set can be downloaded from https://www.kaggle.com/datasets/henryokam/prosper-loan-data and was cleaned using the code provided by https://github.com/jmajakwara/Credit-risk. The mortgage dataset can be downloaded from http://www.creditriskanalytics.net/datasets-private2.html.

The simulation results were obtained using the codes: MC_Sim_log_low.R and MC_Sim_log_high.R. The real data results were obtained by running the codes: Propser_log_cure.R, Prosper_imp_pmm.R, Prosper_shap.R, and Mortgage_analysis.R.
