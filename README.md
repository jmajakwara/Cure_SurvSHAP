# Cure rate and SurvSHAP Modelling

These files are based on an article titled: *From Cure Rate Models to Explainable Survival Analysis: SurvSHAP Based Insights for Credit Risk* to appear in the Journal of Applied Stochastic Models in Business and Industry.

The Prosper P2P data set can be downloaded from https://www.kaggle.com/datasets/henryokam/prosper-loan-data and was cleaned using the codes provided by https://github.com/jmajakwara/Credit-risk. The mortgage dataset can be downloaded from http://www.creditriskanalytics.net/datasets-private2.html.

The simulation results were obtained using the R codes Sim_1000_MC.R, Sim_Propser.R and Sim_mortgage.R and the real data analysis with Propserx.R and Mortgage.R
